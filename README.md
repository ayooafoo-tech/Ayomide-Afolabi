## Project Overview
Inkspire is a manufacturing and inventory
management system designed to help organize
production operations, materials, inventory,
and replenishment activities.

## Project Objectives
- Manage manufacturing materials
- Track inventory and stock levels
- Monitor production work orders
- Manage factory production lines
- Track material transactions
- Handle inventory replenishment requests

## Database Design
The database design includes:
- Factory
- Employee
- Material
- Product
- WorkCenter
- WorkOrder
- Stock
- BOM
- Sensor
- SensorEvent
